### R-01 技术咨询：Godot 多人联机可行性

**用户请求**：确认用 Godot 做类 Cambio 多人卡牌游戏的难度、与其它引擎对比、是否需要租服务器、测试阶段能否不租服务器。

**AI 答复**：
- Godot 4 自带高层多人 API，回合制卡牌游戏难度低，优于 Unity/Unreal 的同等开发成本
- 测试阶段不需要服务器（localhost/局域网直连即可）；上线公开需要 VPS 或中继
- 推荐主机权威（host-authoritative）模型 + 逻辑/传输分离，为未来 VPS 迁移留口

**用户反馈**：继续追问架构细节。

**用户请求**：确认自己电脑 host 能否公网访问、Godot 官方中继方案是什么、4 人测试是否够用。
