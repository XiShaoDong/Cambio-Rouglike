## 三、开发约定

- **服务器权威不变**：所有规则状态改动在 `game_state.gd` 或由其广播；UI 只做投影。
- **回归基准**：`verify_protocol`(38/38) + `verify_swap`(10/10) + `verify_duel`(31/31) + `verify_reconnect`(41/41) + `verify_kongbaya`(15/15) + `verify_settlement`(38/38) + `verify_series`(41/41) + `verify_economy`(33/33) + `verify_shop` + `verify_hint`(8/8) + `verify_net` 双实例 + `verify_proxy` 全场景（baseline/latency/loss/jitter/reconnect）双实例，每次改动保持全绿。**一键全量**：`tools/run_all_tests.sh`。
- **拆分类不做行为变更**：只搬代码，不改变判定/流程。
- **不启动 GUI**：用 headless unit test 验证（见交接说明第 8 节）。
