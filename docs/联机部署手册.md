# KONG 联机部署手册（让朋友远程一起玩）

> **目标**：用**一台 VPS 做专用服务器 + 目录服务**，朋友输"房间码"即可远程加入（无需公网 IP/端口转发，无需 Steam）。
> **路线**：专用服务器（headless，不占玩家座位，P1）+ 房间码（P2）。客户端只需**能连出去**。

## 1. 架构总览

```
朋友A/朋友B ──输码──▶ 目录服务(TCP 8080)：码 → 服务器地址 ──▶ 直连专用服务器(UDP 7007)
你(房主/管理) 在 VPS 上跑： 目录服务 + 专用服务器
```

- **专用服务器**：`scenes/server.tscn`（P1），启动即向目录登记 → 打印**房间码**。
- **目录服务**：`server/directory/directory.py`（P2），把码解析成服务器地址。
- 单房：一次一局（和朋友玩足够）。

## 2. 把代码放到 VPS

```bash
# 在 VPS 上
sudo apt-get update && sudo apt-get install -y python3 git

cd kong
git checkout agent/feature-online     # 未并入 main 前用该分支；已并入则用 main
```

## 3. 安装 Godot（跑专用服务器）

**二选一**：

**A. VPS 直接装 Godot headless（推荐，简单）**
```bash
# 本机：x86_64 + Ubuntu 22.04（架构=linux.x86_64）
cd /opt && sudo mkdir -p godot && cd godot
sudo curl -L -o godot.zip "https://github.com/godotengine/godot/releases/download/4.6.2-stable/Godot_v4.6.2-stable_linux.x86_64.zip"
sudo unzip -o godot.zip && sudo chmod +x Godot_v4.6.2-stable_linux.x86_64
sudo ln -sf /opt/godot/Godot_v4.6.2-stable_linux.x86_64 /usr/local/bin/godot
godot --version     # 期望 4.6.2.stable
```
> 若上面的下载地址失效，去 `https://godotengine.org/download/archive/4.6.2-stable/` 取 "Linux" 的 x86_64 包。
> 缺 `unzip` 先 `sudo apt-get install -y unzip`。

**B. 本地导出 Linux 服务器包**（需在开发机装导出模板 + `export_presets.cfg`；未做，见 §6）→ 上传运行。

> 首次 `godot --headless --path . res://scenes/server.tscn` 会导入资源（稍慢），之后正常。

## 4. 启动服务（先手动验证，再 systemd）

### 4.1 目录服务
```bash
cd ~/kong/server/directory
python3 directory.py --port 8080 --advertise-host 129.213.203.137 &   # 前台测试；正式用 systemd
curl -s localhost:8080/health          # 期望 {"ok":true,"rooms":0}
```
> `--advertise-host`：因为服务器与目录**同机**，目录看到的源 IP 是 `127.0.0.1`；用它把房间地址改写成**公网 IP**，否则朋友会连到自己的 127.0.0.1。

### 4.2 专用服务器（连到目录）
```bash
cd ~/kong
godot --headless --path . res://scenes/server.tscn -- --port 7007 --directory http://127.0.0.1:8080 --advertise 129.213.203.137
```
预期日志：
```
[KONG] dedicated server listening on UDP 7007
[KONG] room code: XXXX      ← 把这串码发给朋友
```
> `--directory` 也可省略，改在 `user://settings.cfg` 里配（服务器上的 Settings）。

### 4.3 systemd 常驻（正式）

`/etc/systemd/system/kong-directory.service`：
```ini
[Unit]
Description=KONG Directory
After=network-online.target
[Service]
User=kong
WorkingDirectory=/home/kong/kong/server/directory
ExecStart=/usr/bin/python3 /home/kong/kong/server/directory/directory.py --port 8080 --advertise-host 129.213.203.137
Restart=always
[Install]
WantedBy=multi-user.target
```

`/etc/systemd/system/kong-server.service`：
```ini
[Unit]
Description=KONG Dedicated Server
After=network-online.target kong-directory.service
[Service]
User=kong
WorkingDirectory=/home/kong/kong
ExecStart=/usr/local/bin/godot --headless --path . res://scenes/server.tscn -- --port 7007 --directory http://127.0.0.1:8080 --advertise 129.213.203.137
Restart=always
RestartSec=3
[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now kong-directory kong-server
journalctl -u kong-server -f      # 看房间码
```

## 5. 开防火墙（两层，缺一不可）

1. **Oracle 云**：VPS 的 **Security List / NSG** → 加入方向 Ingress：
   - `UDP 7007`（游戏）、`TCP 8080`（目录）；用账号再加 `TCP 8090`。
2. **系统防火墙**（Ubuntu）：
   ```bash
   sudo ufw allow 8080/tcp
   sudo ufw allow 7007/udp
   sudo ufw allow 8090/tcp     # 可选
   sudo ufw reload
   ```
   （Oracle Linux 镜像默认 iptables 更严；Ubuntu 用 ufw 即可。）
3. **验证外网可达**：从你的电脑 `curl http://129.213.203.137:8080/health` 应返回 `{"ok":true,...}`。

---

## 6. 客户端导出与分发（让朋友能双击运行）

> 目前只能在 Godot 编辑器里跑 → 朋友需**可运行包**。

1. 开发机装 **导出模板**（编辑器 → 编辑器 → 管理导出模板，对应 4.6.x）。
2. 新增**导出预设**（`export_presets.cfg`，当前仓库没有）：
   - Linux / Windows Desktop / macOS —— 你朋友用哪个就导哪个。
   - macOS 分发有 Gatekeeper 签名问题（朋友可能需右击打开）；Windows 最省事。
3. 导出后把包发给朋友（Zip）。
4. **让客户端指向你的服务器**：两种方式
   - 简单：朋友进游戏 → **ESC → 设置 → 目录地址** 填 `http://<公网IP>:8080`；
   - 省事：把默认目录地址内置（见下"可选改进"），朋友开箱即用。

---

## 7. 朋友加入步骤

1. 打开游戏 → **ESC → 设置 → 目录地址** = `http://129.213.203.137:8080`。
2. 主菜单**房间码**框输入你给的码（如 `J7K2Q9`）→ 点**加入房间**。
3. 进入房间 → 准备 → 你（房主视角=首进入者/或服务器局）开始 → 开玩。

> 谁"开局"：专用服务器模式下，**第一个进入的玩家 = 房主**（`host_seat`），拥有"开始对局"按钮。

## 8. 排障

| 症状 | 排查 |
| --- | --- |
| 朋友"加入失败：房间不存在或已过期" | 目录地址填错 / 目录进程没起 / 码过期(TTL 30min) / 服务器没登记（看 server 日志） |
| 目录 `/health` 外网不通 | 云 Security List 或 ufw 没放 `8080/tcp` |
| 连上了但卡在连接 | 游戏端口 `7007/udp` 没放行 / 服务器没在跑 |
| 服务器日志没有房间码 | server 启动时 `--directory` 未配 或 目录未就绪（systemd 顺序） |
| 掉线连不回 | 房间被"0 人 60s"回收 或 服务器重启；仅限重连宽限内 |

## 9. 当前限制 & 后续

- **单房**：一台服务器一次一局（够了；多房 = P2d）。
- **无账号/Steam**：可选；不影响联机。
- **可选改进**（我随时可做）：
  - 客户端**内置默认目录地址**（免朋友手填）；
  - 服务器日志/接口**显眼输出房间码**（甚至有"查看当前码"的小接口）；
  - `export_presets.cfg` + 一键导出脚本。

## 10. 一键部署脚本（推荐）

仓库含 `tools/deploy_vps.sh`，把 §2–§5 的步骤串起来（装依赖/Godot、克隆、切分支、装 systemd、开 ufw）。

```bash
# 在你的 Mac 上，把脚本+仓库推上 VPS（或直接在 VPS 上 git clone 后跑）：
scp tools/deploy_vps.sh ubuntu@129.213.203.137:~/
ssh ubuntu@129.213.203.137 'bash ~/deploy_vps.sh'
```

脚本做的事（**幂等**，可重复跑）：
1. `apt-get install python3 git unzip`；安装 Godot 4.6.2（linux.x86_64 → `/usr/local/bin/godot`）。
2. `git clone`（或 `git pull`）到 `~/kong`，`git checkout agent/feature-online`。
3. 写 `/etc/systemd/system/kong-{directory,server}.service` 并 `enable --now`。
4. `ufw allow 8080/tcp 7007/udp 8090/tcp`。
5. 打印**房间码**（`journalctl -u kong-server`）。

> 私钥登录：脚本默认用 `ubuntu` 用户、仓库走 HTTPS（公开仓无需 key）。若仓库私有，请在 VPS 配好 GitHub 凭证后把 `REPO` 换成 SSH 地址。

---

## 11. 最小路径（TL;DR）
1. VPS：跑 `tools/deploy_vps.sh` → 开 7007/udp + 8080/tcp（云+系统两层）。
2. 开发机：导客户端包发给朋友（或让朋友用编辑器跑）。
3. 朋友：设置目录地址 `http://129.213.203.137:8080` → 输码加入。
