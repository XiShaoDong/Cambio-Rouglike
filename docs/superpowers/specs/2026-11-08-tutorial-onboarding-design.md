# 新手教程（3D 教学局 + 首局轻提示）设计

> 纯客户端展示与本地脚本层：不改 `GameState` / 网络 / 协议 / 快照 / 既有规则测试。教学局是一段本地时间线（预置状态 + 定时动作 + 4 个真操作点），复用 3D 对局视图渲染。目标：新玩家 3–5 分钟亲手走完一次基础牌局。

## 1. 已确认决策（2026-11-08）

| 决策 | 选择 | 说明 |
| --- | --- | --- |
| 教程形态 | 独立教学局 + 首局轻提示 | 教学局可跳过，首局提示各弹一次 |
| 覆盖范围 | 只教基础牌局 | 记忆、抽/换/弃、能力一览、贴牌、Kongbaya、结算 |
| 教学对手 | 1 个脚本对手 | 2 人桌，其余两个座位隐藏 |
| 桌面形态 | 3D 桌面 | 与真局同一套准星/点击交互，学习可迁移 |
| 引导强度 | 回放为主 + 4 个关键步真操作 | 抽牌、替换、贴牌、Kongbaya 由玩家亲手完成；点错给纠正 |
| 入口 | 主菜单「新手教程」+ 首次高亮推荐 | 不强制；完成/进入后去高亮；设置内可重看 |
| 实现形态 | 预置回放 + 点击推进 | 本地脚本时间线，不跑真实服务器规则 |

## 2. 目标与非目标

**目标**

- 玩家在 3–5 分钟内理解并亲手完成：抽牌 → 替换 → 抢贴 → 喊 Kongbaya → 看结算。
- 建立三个核心直觉：牌是背面的、靠记忆；低分获胜；弃牌即开抢贴窗口。
- 所有教学内容可跳过、可重来、可退出，任何路径都不卡死。

**非目标（V1）**

- 不做 7–Q 能力的实操教学、不做多人同时贴牌/比拼、不教商店/遗物/道具卡/随机效果。
- 不做 AI 策略、不接网络、不改服务器规则、不改 2D 对局。
- 不做语音旁白（首版纯文字）。

## 3. 入口与出口

- 主菜单固定按钮「新手教程」；首次启动时按钮带高亮 +「推荐先玩」角标，**不强制进入**。
- 首次标记与完成标记持久化到本地；完成后按钮恢复正常样式。
- 设置界面提供「重看新手教程」入口（清空标记并进入教学局）。
- 结束页出口：`开始第一局`（进入现有大厅/建房流程）、`再练一次`、`返回主菜单`。
- 任意时刻可「跳过本步」「跳过教程」（二次确认）「重新开始」。

## 4. 章节总览

| 章 | 名称 | 形式 | 目标时长 | 玩家动作 |
| --- | --- | --- | --- | --- |
| 0 | 开局与记忆 | 回放 | 15s | 点「我记住了」 |
| 1 | 抽牌 | **真操作** | 15s | 点抽牌堆 |
| 2 | 换牌 | **真操作** | 30s | 点「替换」→ 点目标槽位 |
| 3 | 对手回合 | 回放 | 20s | 点「继续」 |
| 4 | 抢贴牌 | **真操作** | 40s | 点自己那张已知的 5 |
| 5 | 能力一览 | 回放 | 20s | 点「继续」 |
| 6 | 喊 Kongbaya | **真操作** | 20s | 点铃铛 |
| 7 | 最终轮与结算 | 回放 | 40s | 点「继续」 |
| 8 | 要点回顾 | 静态 | 15s | 选出口 |

## 5. 逐章流程

### 第 0 章 · 开局与记忆（回放）

- 镜头对准自己桌面的 4 张背面牌。
- 提示：「你的 4 张牌全程背面朝上，只能靠记忆。」
- 脚本自动翻开下排两张（槽 2/3：`5`、`K`）并保持 2s，随后盖回。
- 提示：「记住它们。之后除了用能力，不会再给你看。」→「我记住了」。

### 第 1 章 · 抽牌（真操作）

- 提示：「轮到你。点抽牌堆拿一张牌。」抽牌堆金色脉冲高亮。
- 点对 → 抽牌飞牌（复用 `CardFly`）→ 大牌竖立显示 `7`。
- 点弃牌堆 → 红色 toast：「这次先点抽牌堆。弃牌顶也能拿，但只能用来替换，稍后讲。」停留原步。

### 第 2 章 · 换牌（真操作）

- 大牌旁出现「替换 / 弃掉 / 使用能力」，高亮「替换」。
- 玩家点「替换」→ 高亮目标槽位（槽 1，原 `2`）→ 点击后旧牌飞入弃牌堆。
- 点「弃掉」或「使用能力」→ toast：「先学替换，弃牌和能力本章跳过。」停留原步。
- 点错槽位 → toast：「把这张牌换进高亮的那个位置。」停留原步。
- 成功后文案：「旧牌进弃牌堆 = 公开信息；同时**贴牌窗口**打开了，所有人可以抢答。」

### 第 3 章 · 对手回合（回放）

- 脚本对手自动抽牌、弃掉一张 `5`，弃牌顶变为 `5`，贴牌窗口开启。
- 提示：「别人的回合你不能操作，但**贴牌窗口**里可以随时抢。」

### 第 4 章 · 抢贴（真操作）

- 提示：「弃牌堆顶是 **5**。你记得哪张背面牌是 5？点它！」
- 点对（槽 2 的 `5`）→ 翻牌 → 绿光 → 贴中自己：牌进弃牌堆、手牌 −1。
- 点错 → 翻牌红光标错 + 罚牌动画 + toast：「贴错罚抽 1 张，窗口继续，可以再试。」停留原步。
- 成功后补充：「贴中别人的牌时，还要从自己手里交一张给对方。」

### 第 5 章 · 能力一览（回放 / 蒙太奇）

- 本章是**能力蒙太奇**，不严格占用回合，只演示效果。
- 对手演示一次 7/8 看自己（蓝光 + 闭眼占位面）。
- 文案列表：`7/8 看自己一张 / 9/10 看别人一张 / J 盲换 / Q 看了再决定 / K=−1 / Joker=0`。
- 补一句：「从弃牌堆拿的牌不能发动能力。」

### 第 6 章 · 喊 Kongbaya（真操作）

- 贴牌解决后恢复玩家抽牌阶段（仍是同一回合，玩家尚未抽牌），铃铛绿环高亮。
- 提示：「觉得自己的分够低了？点铃铛喊 **Kongbaya**。」
- 点铃铛 → 玩家停止行动，脚本对手完成一次最终行动。
- 先点抽牌 → toast：「先别抽，试着喊 Kongbaya。」停留原步。

### 第 7 章 · 最终轮与结算（回放）

- 对手最终行动 → 进入 3s 结算贴牌窗口（复用倒计时/贴牌状态行）→ 翻牌 → 展示排名。
- 复用结算页视觉：低分第一；文案点明「第一 +40 / 中间 +10 / 垫底 0 且 −1 生命」。

### 第 8 章 · 要点回顾

- 四张要点卡：① 牌是背面的，靠记忆；② 低分获胜；③ 弃牌就开抢贴窗口；④ 想收手就喊 Kongbaya。
- 出口：开始第一局 / 再练一次 / 返回主菜单。

## 6. 引导层与交互规范

- **交互模型（教学局特例）**：固定镜头 + **鼠标指针直接点击**（`Table3dPicker.pick(cam, world, 鼠标屏幕位置)` + `Area3D` meta），再加屏幕空间提示/按钮。理由：新手第一次面对 3D 时，"移动鼠标环视 + 中心准星瞄准"是额外负担；教学局不需要环视，固定视角 + 可见鼠标最易学。结束页用一句话说明"真局是移动鼠标环视、用屏幕中心准星瞄准后点击"。
- **镜头**：进入教学局时对 `viewer` 座位取景一次后锁定（`Table3dCamera.framing_enabled=false`），不回正、不响应鼠标环视。
- **顶部**：章节名 + 进度点（`n/N`）。
- **中下**：一句话提示卡（沿用 `HintHud` 视觉），下方显示当前可做的操作。
- **目标高亮**：抽牌堆/弃牌堆/铃铛/目标卡槽使用金色脉冲描边（复用 `CardBlock` 的边框体系）；不遮挡牌面。
- **继续**：提示板上的「▶ 继续」按钮 + `Enter` 同效；仅回放段出现。
- **纠错**：红色 toast，3s 自动消失，不清空当前步骤状态。
- **角落菜单**：跳过本步 / 跳过教程 / 重新开始。
- **文案集中**：所有文本放 `TutorialText`（仿 `HintText`），便于以后本地化与审校。
- 回放段内点击牌桌：提示「先看完这段演示」，不进入真实交互，避免与时间线抢状态。

## 7. 首局轻提示（衔接真对局）

只在真局各弹一次，状态持久化到本地：

| 触发点 | 文案 |
| --- | --- |
| 首次 `INITIAL_PEEK` | 看下排两张，记住它们，之后不再显示。 |
| 首次轮到自己 | 点抽牌堆或弃牌堆顶。 |
| 首次贴牌窗口 | 弃牌顶是 X，记得哪张是 X 就点它抢贴。 |
| 首次进入商店 | 货币可买遗物/道具卡；遗物只对持有者生效。 |
| 首次结算 | 低分获胜；垫底扣 1 生命。 |

提示为轻量 toast/提示条，不弹模态、不锁操作。

## 8. 技术设计

### 8.1 架构

- **本地时间线**：`TutorialController` 持有 `TutorialStep` 数组，按步骤进入/推进；回放段用 `await` + Tween/`CardFly` 播动画，真操作段等待输入回调。
- **渲染复用**：每个步骤产出一份**与 `HiddenInfo` 同形状的快照字典**，直接喂 `Table3dView.render(state)`。不新增渲染分支。
  - `Table3dView.render` 实际读取的字段：`viewer_id`、`players[]`（`id/name/slots/count/health/currency/offline/color`）、`current_player`、`phase`、`draw_count`、`discard`、`discard_count`、`pending`、`offline_players`、`run`。
  - 未知牌槽位保持"空 card dict"（只给令牌、不含 `rank/suit/value`），已知牌才带牌面。
- **2 人桌**：快照 `players` 只含 seat 0/1；`Table3dView.render` 已按 `players` 顺序启用 Seat 节点并隐藏其余座位（现有行为，已验证）。因此**不改 `table3d.tscn`**。
- **交互入口**：教学场景用鼠标屏幕坐标调 `Table3dPicker.pick(cam, world, mouse_pos)`，命中结果转 `TutorialController.pick(meta)`；不调用 `GameState.request_*`，不产生网络消息。
- **牌值单一来源**：分值/点数循环统一读 `KongRules.card_value` / `next_rank_in_cycle`，避免第二套规则漂移。
- **进度存储**：`TutorialProgress`（薄壳，可注入路径）读写 `user://tutorial.cfg`，字段 `seen`（首次高亮已消）、`completed`、`first_hints`（各提示已展示的位）。

### 8.2 固定牌序（可复现）

- 玩家 seat0：`[9, 2, 5, K]`（槽 2/3 = 下排 `5`、`K`，为开局可见）。
- 对手 seat1：`[4, 5, 7, J]`（手牌从不变）。
- 抽牌堆顶：`7`（玩家抽到）；其后依次 `5`、`2`（对手抽到）。
- 流程：玩家把 `7` 替换进槽 1（原 `2` 进弃牌堆）→ 对手抽到 `5` 并弃掉（弃牌顶变 `5`）→ 玩家贴自己槽 2 的 `5`。
- 第 5 章蒙太奇：对手抽到 `7` 并看自己槽 3 的 `J`（不严格占回合）。
- 玩家最终手牌 `[9, 7, 5, K]` → 贴掉 `5` 后为 `[9, 7, ·, K]`，总分 15。
- 对手最终行动抽到 `2` 并弃掉，手牌仍 `[4, 5, 7, J]`，总分 26 → 玩家更低、获胜。
- 结算用预置 `result` 字典（含上述排名与奖励），不跑真实计分。

### 8.3 步骤机

每个步骤声明：`id / title / text / mode(replay|interact) / setup_state() / on_enter() / expect(meta) / on_correct() / on_wrong(meta) / advance_to`。
- `interact` 步只有 `expect` 返回 true 才推进；其余输入走 `on_wrong` 给纠正。
- `replay` 步在动画完成或玩家点「继续」/`Enter` 后推进。
- `skip_step()` 直接结算到该步结束态再进入下一步；`restart()` 重建初始状态。

## 9. 边界与异常

- 跳过本步：立即把当前步收尾（回放动画直接到终点、真操作步模拟正确结果），再进入下一步。
- 跳过教程：二次确认 → 结束页（不直接退游戏）。
- 重新开始：清空时间线与牌局状态，回到第 0 章。
- 中途 `Esc`：不退出教程，只暂停并显示角落菜单（与设置界面互斥）。
- 窗口关闭：沿用主程序「房间中回大厅、初始大厅才退出」的现有逻辑；教程视为本地页面，退出即回主菜单。
- 重复点击/连点：`TutorialController` 用步骤锁，防止动画期间重复推进。
- 3D 拾取：目标物体保留较大拾取盒；高亮与纠错文案同时给出，避免"点不中却不知道"。

## 10. 测试与验收

**自动化（headless）**

- `verify_tutorial`：步骤顺序；4 个正确路径；每类错误输入（点弃牌堆/点弃用/点错槽/贴错/先抽牌）不推进且给纠正；`skip_step/restart`；固定牌序；快照字典最小字段；`TutorialProgress` 注入路径读写。
- 注册到 `tools/run_all_tests.sh`；`--quick` 无回归。
- 不启动 GUI；3D 实际点击手感由人工验收记录。

**人工验收**

- 首次玩家 3–5 分钟完成，4 个关键步均亲手操作。
- 3D 下所有高亮目标可命中；提示不遮挡关键牌区。
- 任意跳过/重来/退出路径不卡死。
- 首局 5 条轻提示各出现一次且不影响操作。

## 11. 风险与缓解

| 风险 | 缓解 |
| --- | --- |
| 教学规则与正式规则漂移 | 只覆盖基础；牌值读 `KongRules`；关键流程写进 `verify_tutorial` |
| 3D 准星点击对新玩家偏难 | 目标加大拾取盒 + 金色脉冲 + 纠错提示；继续键支持 `Enter` |
| 教学场景依赖 `table3d.tscn` 结构 | 只实例化、不改结构；节点路径契约由现有 `verify_table3d` 保护 |
| 文案量大且分散 | 全部集中到 `TutorialText` |
| 首局提示打扰老玩家 | 只弹一次 + 本地持久化 + 设置可重置 |
