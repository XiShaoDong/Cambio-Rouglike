# KONG 遗物效果 v1（Milestone 4）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 M3 已入库的两件 v1 遗物接入**实际效果**：`Joker 变换`（抽到 Joker 时可变换为任意牌；未变换时 Joker 分值 +2）与 `防守护盾`（下一局随机保护一格，免疫他人贴牌与交换）。不改商店/拍卖流程。

**Architecture:** 全服务器权威，采用**具体钩子**（不引入通用 RunModifier 框架）：`_deal_new_match` 末尾调 `_apply_match_start_relics()`（护盾：随机选格 + 消耗遗物）；抽到 Joker 走新 RPC `request_joker_transform`（客户端弹选牌面板）；Joker +2 由 `GameState._relic_card_value(seat, card_id)` 统一（服务器 `_calculate_ranking` 与快照揭示同步用，保证结算显示与排名一致）。护盾格免疫：`slap_system.attempt` 与 `effect_system._blind_swap`/`_start_queen`/`_server_q_decision` 加 `PROTECTED` 拒绝。`enable_relics=false` 或未持遗物时全部 no-op，基础模式零影响。

**Tech Stack:** Godot 4.6 / GDScript / ENet。headless 单测（`tests/verify_relics.tscn`）。

**Spec:** `docs/superpowers/specs/2026-09-07-series-shop-relics-design.md` §6；用户确认（2026-09-08）：Joker 变换=抽牌阶段（含弃牌堆顶）抽到 Joker 可变换、未变换 +2；护盾=购买后下一局生效、随机保护一格、免疫贴牌+交换、看牌/自操作不受影响、一局后失效。

## Global Constraints

- 保持 `GameState` 服务器权威、私有快照、贴牌服务器时序三条架构不变量不变。
- 遗物效果只在**持有者**相关处生效；`enable_relics=false` 或 `run_state.relics` 为空时一律 no-op（基础模式零影响）。
- 护盾保护的是**槽位**（不随卡移动）：槽内换新卡仍受保护；自己替换/弃牌/看牌不受影响；他人贴牌与 J/Q 交换指定受护盾槽位 → 拒绝（`RejectCode.PROTECTED`）。
- Joker +2 只作用于**牌面仍是 JOKER 且持有者持有 Joker 遗物**的结算分值；变换后不再是 JOKER，按新点数计。
- 新 UI 优先 `.tscn`（Joker 变换面板 `scenes/ui/joker_transform_panel.tscn`）。
- 遗物实现前必须先填设计卡（`docs/relic_joker_transform.md`、`docs/relic_guard_shield.md`）；改协议前更新 `docs/网络协议_V1.md`；改规则前更新 `docs/KONG_开发文档.md`。
- 每次改动跑回归 `tools/run_all_tests.sh --quick`；提交 `feat/fix/doc` 分类。

func _apply_match_start_relics() -> void:
	for seat in _alive_order():
		players[seat].protected_slot = -1
		if run_state.get("relics", {}).has(Relics.GUARD_SHIELD_ID):
			var count := players[seat].cards.size()

func _is_protected(seat: int, slot: int) -> bool:
	return players.has(seat) and int(players[seat].get("protected_slot", -1)) == slot

## Joker 变换：持有 Joker 遗物者在抽牌阶段抽到 Joker（抽牌堆或弃牌堆顶），可选变换为任意牌。
func _server_joker_transform(sender: int, rank: String, suit: String, action_id := "") -> void:
	if phase != Phase.TURN_DECISION:
		_reject(sender, RejectCode.INVALID_PHASE, action_id)
		return
	if _guard_suspended(sender, action_id):
		return
	if _guard_spectator(sender, action_id):
		return
	if sender != current_player_id:
		_reject(sender, RejectCode.NOT_CURRENT_PLAYER, action_id)
		return
	if pending_draw.is_empty() or not _check_action_id(sender, action_id):
		_reject(sender, RejectCode.DUPLICATE_OR_EXPIRED_ACTION, action_id)
		return
	if not run_state.get("relics", {}).has(Relics.JOKER_TRANSFORM_ID):
		_reject(sender, RejectCode.ABILITY_FORBIDDEN, action_id)
		return
	var cid: String = str(pending_draw.card_id)
	if str(cards[cid].rank) != "JOKER":
		_reject(sender, RejectCode.ABILITY_FORBIDDEN, action_id)
		return
